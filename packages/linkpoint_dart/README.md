# linkpoint_dart

Modern Dart and Flutter SDK for Second Life standards, protocol serialization, LLSD, and viewer contracts.

## Features

- **LLSD Coders**: Native Dart implementation of XML, Binary, and Notation LLSD serialization.
- **Protocol Packets**: Packet headers, zero coding, and packet parsers.
- **FFI Bindings**: Native bridge to shared Rust core.
- **Flutter Widgets**: Reusable UI components for metaverse viewer apps.

## Installation

```yaml
dependencies:
  linkpoint_dart: ^0.1.0
```
