🎯 WHY EACH WRAPPER SOLUTION WORKS
══════════════════════════════════════════════════════════════════════════════

ELECTRON WORKS BECAUSE:
  • Express runs in Node.js process (not browser)
  • Node.js fetch/https has NO CORS restrictions
  • Server-to-server communication
  • PWA talks to localhost (same origin, no CORS)
  • Localhost proxy talks to SL (no CORS in Node.js)

TAURI WORKS BECAUSE:
  • Rust runs in native process (not browser)
  • Reqwest (Rust HTTP) has NO CORS restrictions
  • Native async HTTP client
  • PWA talks to localhost (same origin)
  • Rust proxy talks to SL (no CORS in native code)

CAPACITOR WORKS BECAUSE:
  • Uses platform native HTTP (not browser fetch)
  • Android: HttpURLConnection (Java)
  • iOS: URLSession (Swift)
  • Native HTTP is NOT subject to browser CORS policy
  • Direct connection to SL with native code

BROWSER FAILS BECAUSE:
  • Uses browser fetch API
  • Browser enforces CORS policy
  • SL doesn't send Access-Control-Allow-Origin header
  • Browser blocks the request
  • This is browser security, not a bug


🔐 SECURITY MODEL
══════════════════════════════════════════════════════════════════════════════

ELECTRON:
  Main Process (Node.js)
    • Can do anything
    • Runs Express server
    • Network access unrestricted
  
  Renderer Process (Chromium)
    • Sandboxed
    • contextIsolation: true
    • No nodeIntegration
    • Secure communication via IPC
  
  Proxy:
    • Binds to 127.0.0.1 ONLY
    • Not accessible from network
    • Only PWA can use it

TAURI:
  Rust Backend
    • Memory-safe
    • No garbage collection overhead
    • Minimal attack surface
  
  WebView Frontend
    • System WebView (not bundled)
    • Sandboxed
    • Limited API surface
  
  IPC:
    • Type-safe Rust ↔ JS bridge
    • Explicit command allowlist

CAPACITOR:
  Native App
    • Platform sandbox (iOS/Android)
    • Permission system
    • User must grant permissions
  
  WebView
    • Isolated from native code
    • Explicit plugin bridge
    • Capacitor validates all calls


💡 KEY INSIGHT
══════════════════════════════════════════════════════════════════════════════

The wrappers don't "hack" CORS. They provide a legitimate workaround:

  Browser CORS applies to: Browser JavaScript → External Server
  
  Wrappers change this to:
    Browser JS → Localhost → External Server
    
  Where:
    • Browser → Localhost = Same origin (no CORS!)
    • Localhost → External = Server code (no CORS!)
  
  Or (Capacitor):
    • Native HTTP → External = Not browser (no CORS!)

This is the STANDARD solution for PWA + native apps.
