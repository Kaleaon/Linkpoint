🚀 QUICK START
═══════════════════════════════════════════════════════════════════

1. OPEN IN BROWSER
   ─────────────────────────────────────────────────────────────
   Simply open: PWA-demo/index.html
   
   OR use a local server:
   
   Python:  python3 -m http.server 8000
   Node.js: npx http-server -p 8000
   PHP:     php -S localhost:8000
   
   Then visit: http://localhost:8000

2. LOGIN (Demo Mode)
   ─────────────────────────────────────────────────────────────
   Grid:     Second Life (Main Grid)
   Username: FirstName LastName
   Password: (any password for demo)
   
   Click "Login" - app will simulate successful connection

3. EXPLORE
   ─────────────────────────────────────────────────────────────
   ☰ Menu → Select view:
   
   🌍 World Viewer - 2D/3D visualization
   💬 Chat        - Send messages
   📦 Inventory   - Browse items
   👥 Friends     - Manage contacts
   🗺️ Map         - Navigate world

4. INSTALL AS APP
   ─────────────────────────────────────────────────────────────
   Desktop: Click install icon in address bar
   Mobile:  Menu → "Add to Home Screen"

⌨️ KEYBOARD SHORTCUTS
═══════════════════════════════════════════════════════════════════

World Viewer:
  W / ↑     Move forward
  S / ↓     Move backward
  A / ←     Move left
  D / →     Move right
  E         Move up
  C         Move down
  
Chat:
  Enter     Send message
  /help     Show commands
  /clear    Clear history
  /me       Send emote
