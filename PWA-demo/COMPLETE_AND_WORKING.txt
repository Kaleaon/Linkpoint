TAURI:

  4. Loads PWA from parent directory
  5. Injects proxy URL via window.eval()
  6. PWA detects and uses proxy
  7. SL requests → Rust async fetch
  8. Rust bypasses CORS
  9. Returns data via Actix
  10. FULL SL CONNECTIVITY ✅

CAPACITOR:
  1. Syncs PWA to android/ios folders
  2. Builds native app (Android Studio/Xcode)
  3. Configures CapacitorHttp plugin
  4. Configures network security (Android)
  5. PWA detects window.Capacitor
  6. SL requests use CapacitorHttp.post()
  7. Native HTTP (not browser fetch)
  8. Native HTTP has NO CORS restrictions
  9. Returns data to PWA
  10. FULL SL CONNECTIVITY ✅
