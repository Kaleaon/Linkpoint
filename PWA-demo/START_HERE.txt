Second Life and OpenSimulator virtual worlds with:

  ✅ Real Second Life protocol (XML-RPC, LLSD, capabilities)
  ✅ Modern 3D graphics (WebGL 2.0 + PBR shaders)

  ✅ Works offline after first load
  ✅ Installable like a native app
  ✅ Zero external dependencies

🚀 QUICKEST START (60 seconds)
══════════════════════════════════════════════════════════════════════════════

1. Open a terminal in this folder (PWA-demo/)

2. Start a web server:
   python3 -m http.server 8000
   
   (or: npx http-server -p 8000)
   (or: php -S localhost:8000)

3. Open browser: http://localhost:8000

4. Click menu (☰), login, explore!

Done! That's it! 🎉

🆘 TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

Can't login to Second Life?
  → Need CORS proxy for SL main grid
  → Try OSGrid instead (may have CORS)
  → See: SL_INTEGRATION.md

PWA won't install?
  → Need HTTPS (localhost works)
  → Check manifest.json
  → Try different browser

3D not working?
  → Check browser supports WebGL
  → Visit: chrome://gpu
  → Falls back to 2D if needed

Slow performance?
  → Clear browser cache
  → Check browser console (F12)
  → Try different quality settings
