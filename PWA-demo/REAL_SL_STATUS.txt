🔒 CORS WORKAROUND
══════════════════════════════════════════════════════════════════════════
Challenge:
  SL login servers don't send CORS headers
  Browsers block direct XMLHttpRequest/fetch

Solutions:
  1. CORS Proxy (development)
     https://cors-anywhere.herokuapp.com/
     
  2. Browser Extension (development)
     "CORS Unblock" or similar
     
  3. Backend Proxy (production - recommended)
     Deploy simple proxy server
     Your-server.com → login.agni.lindenlab.com
     
  4. OpenSim Grids (some have CORS enabled)
     OSGrid and others may allow direct connection
