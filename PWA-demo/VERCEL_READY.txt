🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Service Worker Not Working:
  → Check: https://your-app.vercel.app/service-worker.js
  → Should return: Content-Type: application/javascript
  → Should include: Service-Worker-Allowed: /

PWA Not Installable:
  → HTTPS enabled? (Vercel provides)
  → Manifest valid? Check /manifest.json
  → Service worker registered? Check DevTools
  → Icons correct? Need 512×512 PNG

Assets 404:
  → All paths relative? (./js/ not /js/)
  → Case sensitive? (Linux servers)
  → Files included? (check .vercelignore)

Slow Loading:
  → CDN propagation (wait 1-2 minutes)
  → Cache headers correct?
  → Assets compressed?
