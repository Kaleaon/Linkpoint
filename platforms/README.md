# Linkpoint Platform Implementations

This directory currently contains the non-Android platform implementation work for Linkpoint.

## Primary Focus

The active production client is the **Android app** in the repository root (`app/` and `Linkpoint/`).

## Contents

- `iOS/` – SwiftUI-based iOS exploration and prototypes.

## Android Build (Primary)

```bash
./gradlew assembleDebug
```

## Notes

Web/PWA implementation files were intentionally removed to keep the repository focused on native Android development.
