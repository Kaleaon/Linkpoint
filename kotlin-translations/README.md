# Kotlin Translation Archive

## Purpose
This archive contains original broken Kotlin files (from Java decompilation) and their fixed versions for comparison and reference.

## Structure
```
kotlin-translations/
├── avatar/          - Avatar mesh, skeleton, attachment files
├── mesh/            - Rigged mesh handling
├── terrain/         - Terrain patch compression
├── protocol/        - Network protocol
├── ui/              - User interface
└── utils/           - Utility classes

Each category contains:
- original/  - Original broken files with Java syntax
- fixed/     - Corrected Kotlin files
- tests/     - Unit tests for verification
```
