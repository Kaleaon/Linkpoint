# Documentation archive

This directory contains completed reports and historical task snapshots. They
are preserved as migration evidence, but they do not describe the current
status of Linkpoint Next.

- `project-reports/` contains completion, review, and implementation summaries.
- `status/` contains superseded task lists.

For current project status, use [`../OVERHAUL_PROGRESS.md`](../OVERHAUL_PROGRESS.md).
